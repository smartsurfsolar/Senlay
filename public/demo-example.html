From a coordinate to inspectable environmental evidence.

Every position, station, reading and model value on this page is synthetic. This static example demonstrates the workflow without calling a weather service or LLM. It does not describe a real flight or current conditions.

  1. Input: a synthetic position from a robot or operator.
  2. Compare: the measured and model values, keeping their origins distinct.
  3. Inspect: source age, distance and disagreement.
  4. Review unknowns: use platform and mission checks outside this spot-level profile.
