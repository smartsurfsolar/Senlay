ENVIRONMENTAL EVIDENCE API

Give AI agents access to real-world environmental context.

Senlay gives agents available environmental observations, forecasts and physical context for a location. Responses can expose source, time, distance, disagreement and unknowns. Use them in robotics, marine, agriculture and inspection workflows within each domain’s documented scope. Commercial use requires verified source rights and configuration.

Sensory Layer. Senlay gives software access to available environmental observations and model values with provenance and limitations for review.

One URL, Four Tools

Connect your agent through MCP

Add https://senlay.cloud/mcp to any MCP client that supports remote Streamable HTTP. Anonymous trial access requires no signup, OAuth, or local package.

The MCP SDK negotiates a compatible protocol version during initialize. The stateless gateway provides sense_location, check_operability, list_domains, and get_forecast_trust. Forecast trust remains UNKNOWN until sufficient eligible archived forecast-versus-instrument pairs exist.

MCP configuration 
{
  "mcpServers": {
    "senlay": {
      "url": "https://senlay.cloud/mcp"
    }
  }
}

Optional account tier: add Authorization: Bearer sl_live_... in the client's server headers. Decision support. Humans remain the final authority.

Instructions for AI Agents

If you are an AI agent reading this page

  1. Request the selected coordinate and use list_domains to understand the available domain scopes.
  2. Separate observations from model values. Read source identity, timestamps, distance, disagreement and missing evidence.
  3. Describe profile coverage and configured threshold flags as separate facts.
  4. Keep unknowns visible; do not turn a GO outcome or complete fields into flight or mission clearance.
  5. For drones, Senlay presents wind observations and available model indications of rain and thunderstorms. Local rainfall and lightning are not directly measured by this assessment. Aircraft limits, route, altitude, visibility and operational permission remain outside its scope.
  6. Keep the operator and application in control of the final decision.
Copyable agent prompt 
You are helping an autonomous-system operator understand environmental context at a selected coordinate. Inspect available observations and model values, their sources, timestamps, distance, disagreements and unknowns. Use the requested domain's documented scope. Do not invent missing measurements or turn a threshold result into mission clearance. The operator and application remain responsible for decisions.

Connect Senlay to an environmental context workflow

Use the beta API or MCP to inspect available evidence at a selected coordinate. A marine assistant can review coastal observations; an agricultural agent can inspect weather context; an inspection system can surface stale or missing sources. The drone wind workflow below is one example. Each domain has its own scope and coverage.

Have a sensor instead of an agent? The ingestion protocol, SDK, and gateway are open source on GitHub — see Connect a station for the provider/station/observation sequence.

Request wind evidence for one coordinate

For the drone profile, inspect available wind observations and model values with their source, timestamp, distance and missing evidence. Other returned layers do not expand the profile into mission coverage.

curl 
# Drone wind profile (structured JSON)
curl -H "Authorization: Bearer sl_live_your_key" \
  "https://senlay.cloud/api/v1/pwm?lat=36.01&lng=-5.60&field=drone&profile=wind"

# Plain-text context for the same coordinate
curl -H "Authorization: Bearer sl_live_your_key" \
  "https://senlay.cloud/api/v1/sense?lat=36.01&lng=-5.60&field=drone"

Your agent receives evidence

For drones, Senlay presents wind observations and available model indications of rain and thunderstorms. Local rainfall and lightning are not directly measured by this assessment. Aircraft limits, route, altitude, visibility and operational permission remain outside its scope. The broader API may return other available environmental layers, but those values do not assess aircraft limits, route, altitude, obstacles, visibility, airspace permission or whole-mission suitability.
